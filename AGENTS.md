# Project instructions

This repository is for the course travel application. For Part 1, keep the scope limited to Vue + FastAPI + CSV search. Do not add SQLite or booking CRUD yet.

- Frontend lives in `frontend/`.
- Backend lives in `backend/`.
- Backend reads `backend/data/hotels.csv` and `backend/data/trips.csv`.
- Join hotel and trip records by `hotel_id`.
- Keep the UI simple and readable.
- Verify both a successful hotel search and a no-results search in the browser.
